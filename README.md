# 静岡 来店予定 LINE通知

静岡県内のパチンコホールに来るタレント・演者の予定を、DMMぱちタウンから1ヶ月先まで集めて、毎週日曜の朝にLINEへ送ります。GitHub Actionsで動くので、PCを起動しておく必要はありません。

## 準備

1. LINE公式アカウントを作り、次の2つを用意します。
   - チャネルアクセストークン（長期）
   - 送り先のユーザーID（`U` で始まる文字列）
2. このリポジトリの **Settings → Secrets and variables → Actions → New repository secret** で、次の2つを登録します。

| 名前 | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | チャネルアクセストークン |
| `LINE_TO` | 送り先ID。複数あるときはカンマ区切り（例 `Uxxxx,Uyyyy`） |

送り先を増やす・減らすときは、`LINE_TO` を書き換えます。送り先になる人は、先に公式アカウントを友だち追加しておく必要があります。

## 試しに動かす

**Actions → 静岡 来店予定をLINEに送る → Run workflow** から実行できます。

- 「送信せずに本文だけ確認する」にチェックを入れたまま実行すると、ログに本文が出るだけです。
- チェックを外して実行すると、実際にLINEへ送ります。

## 変更したいとき

- 配信日時を変える：`.github/workflows/weekly.yml` の `cron` を書き換えます（時刻はUTCで、日本時間の9時間前です）。
- 何日先までまとめるか：同じファイルの `DAYS_AHEAD` を書き換えます。

## 注意

- LINEの無料プランは月に送れる通数に上限があります。週1回×数人なら収まります。
- 掲載サイトのレイアウトが変わると、来店予定を拾えなくなることがあります。0件の通知が続いたら、ログを確認してください。
